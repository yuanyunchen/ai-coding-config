# 安静模式延迟验证
默认任务只发实际结果，裸问候不启动模型。旧版“已收到”回执的基线已被替代。

| 场景 | 样本 | p50 ms | p95 ms | 最大 ms | 缺失 |
|---|---:|---:|---:|---:|---:|
| arrival_to_backend_accept | 48 | 95 | 162 | 165 | 0 |
| arrival_to_final | 48 | 135 | 199 | 206 | 0 |
| event_to_visible_progress | 48 | 11 | 165 | 165 | 0 |

上述数字来自本机生产适配器加模拟 Slack 与受控慢附件/模型的 48 轮测试。真实 Codex + 模拟 Slack 的中英文两轮最终答案分别为 4112 ms 和 2687 ms。真实 #test 人类请求与真实 bot 回复均已从 conversations.replies 读取；一个来自线上指标的答案样本为 7791 ms。它只代表单个请求，不足以估计线上 p95。实际网络、Slack 限流和模型负载继续由本机指标表记录；另查待核对发送可发现未确定的交付。
