## 上线核对

- 部署当前源码后确认 Socket Mode、后端连接、历史补取和指标采集。登记目标频道后，在一个获准测试线程检查真实 @、连续追问、审批通知、结果、跨线程／越权隔离、断线恢复与延迟。当前私人桌面会话没有用于该验证。
- 断线补取的可见范围依赖 Slack 可返回的记录。登记前的根消息若从未观察、只有离线期间增加的回复，缺少可定位线程来源。普通问答使用增量上下文，重连时会按登记窗口回扫以核对旧来源编辑和删除。实际频道规模上的补取耗时仍需测量。Slack 当前参考列出 bot token 可用频道历史 scopes。[Slack conversations.replies](https://docs.slack.dev/reference/methods/conversations.replies/)
- 本轮线上操作只有 launchd、启动日志、部署副本与数据库计数的只读检查。未重启动服务，未向 Slack 发消息。
