### 目标
将 Slack 作为现有 Codex 会话的消息与进度入口：被 @ 自动响应、继续相同上下文、查看执行进度，体验接近在当前窗口发消息。

已按用户授权安装 Slack 官方插件和 CLI 并登录目标 workspace。用户选 JavaScript，并明确要求复用现有 Codex 对话，而不是独立 OpenAI/Claude API 聊天机器人。

### 验收标准
Slack 发消息能进入预期的 Codex 会话；上下文与本机窗口连续；公开进度回传；重连不重复执行；事实与未验证项明确区分。
