# 结果 — T04.01/S08 发布性能对照

基线与候选在同机本地 A/B 各完成每组 100 次计量，共 800 次。所有计量都有收件 ACK、模型接口接收回执和回帖回执。错误、超时、缺失和总失败均为 0。候选四组回帖 p95 的变化在 −0.15 到 +1.12 ms 之间，有升有降。这一轮数据没有显示一致的速度改善。

两版使用同一个 Node v24.1.0 进程、相同的本地磁盘与 SQLite 配置、相同的对话和外部模拟延迟。每组每版先预热 3 次，测量交替先运行的版本，前后顺序各占 50 次。代码通过真实的桥接收件校验、路由、持久化和回复发送入口。Slack Web API、Codex 接收与生成、文件准备使用本地模拟器，因此这些数字只适合比较本地的受控路径。真实 Slack、真实 Codex 生成、冷启动和输出图可见性未在此 A/B 测量。
