# Example data report (auto-rater, 2026-11)

Two self-contained pages built from one source: `core.html` (the decision view) and `full.html` (everything, for a reviewer). No external references; open them in a browser. They are the result of the rebuild described in [`../../references/data-report.md`](../../references/data-report.md). Use them to calibrate form, not as a template to copy: the content is one project's.

| Look at | For |
|---|---|
| Summary tiles | four findings, each with one number, one mini chart and a link to its card |
| 1.1 | the one comparison convention, stated once before any number |
| 2.1 Which paradigm | dot rows on a zoomed axis with the chance level and the data's own limit; partial-range rows hollow and paired with the main system on the same range; the "picked after seeing these" label and the held-out rows beside the headline |
| 2.3 | the headline sliced by board position |
| Any block of part 3 | two plain lines → mechanism figure → comparison → ablations |
| 4.2, 4.4 | train and held-out curves against steps; the planted-noise control behind a null result |
| 5.1 to 5.3 | linear x-axis cut at 1,000, limit line, best policy first and the alternatives in their own card |
| Every card's last line | "Data … Model …" small print |
| 7.1 | what did not replicate |

Known weak spots, kept as they are: the held-out check covers 10 of 13 models; the prompted judge covers 62% of tasks; in 2.1 two sub-labels touch the first axis at 1280 px.
