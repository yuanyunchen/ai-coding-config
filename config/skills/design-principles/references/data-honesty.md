# 数据诚实与统计图

数字与图表怎么画、怎么写才不误导。出处见 `provenance.md` D 系列。

---

## 一、图型选择

| 意图 | 图型 |
|---|---|
| 类别对比 | 柱状;类别名 > 8 字改条形(横向) |
| 时间趋势 | 折线 / 面积 |
| 占比(加总约 100%) | 饼 / 环形(≤ 6 扇区);层级占比用树状图 |
| 分布 / 相关 | 散点 / 气泡(半径 ∝ √值) |
| 多维评估 | 雷达(3–6 维,系列 ≤ 3) |
| 逐层转化 | 漏斗(标阶段名 + 数值 + 转化率) |
| 增减拆解 | 瀑布(涨绿跌红,首尾实柱) |
| 流向 | 桑基(带宽 ∝ 值) |
| 二维密度 | 热力 |

不确定时用柱状。同字段多对象的精确比较用**表**,不用图。

## 二、轴与标签

- 柱状图 Y 轴**必须从 0 起**;折线可聚焦数据范围,但标起始值。
- Y 轴 5–7 档,步长取 2 / 5 / 10 的倍数;轴标题带单位(万元 / % / 人)。
- 大数值在数据阶段换算(> 10000 → ÷10000,列名加「(万)」)。
- 时间轴升序;不旋转文字。
- 数据点少时显示数据标签(柱 ≤ 8、线 5–15),过密则隐藏;千分位分隔;百分比留 1 位小数。

## 三、配色

- **少色相、多色阶**:单系列一个深色;多系列取同一色系的不同明度;系列 > 7 先合并。
- **焦点对比**:一个焦点用暖色,其余系列全用灰。
- **语义优先**:正/增长/达标 = 绿,负/下降/未达标 = 红,中性/基准 = 灰,警告 = 橙,信息 = 蓝;同比/环比 = 本期实色 + 上期同色 35% 透明。
- 红绿必须同时带 ↑↓ 或 +/-(见 visual-encoding §二)。
- 默认数据色板(专业蓝):`#0A345E #18ADED #A6A7AD #1A82EB #74CEF4 #E1E2E4 #138ABE #76B4F3 #898A91 #0E688E`。
- 文字灰阶:主 `#0A345E`/`#1C1C1A`,次 `#3D4852`,网格/脚注 `#898A91`;浅灰只作装饰。
- 禁止:渐变、阴影、发光、3D 效果。

## 四、诚实口径(可信度的命根)

- **采样标注**:采样估计在**首次出现处**带口径小标(如「1/10 取模采样」)+ 一句校验说明;只报比率或占比,绝对数标「≈ / 上界」。措辞准确(取模不说成「哈希均匀」)。
- **反例不藏**:有反例就摆(「250 国里 27 国反向占优」),不只挑顺的讲。
- **断线不插值**:趋势缺点就断开并标记(✕ 或空心点),**绝不连线假装连续**;超时未取标「超时未取」,不补 0、不外推。
- **推导值透明**:非直测的值给出算式与口径等价性(放展开区),标「推导」而非「实测」。
- **近似函数**:标误差范围与是否改变方向(「误差 < 2%,不改方向」)。
- **样本与外推边界**:小样本结论标「仅基于 N 样本,不外推」。
- **恒等式自洽**:分解各部分之和 = 总数,在报告里可当场验证。
- **同名不同量分开讲**:数值接近但分母不同的量明确区分。
- **同一个量全产物同口径同数**:指标卡、图、正文里同一个量必须一致,否则每处显式标算法;优先级 精确 > 近似 > 采样外推(标上界)。
- **可读名**:对外展示把 id 映射成名字;映射缺失回退原值并注明。
- **面积成比例**:维恩等面积图须面积 ∝ 数量,不用固定重叠示意。

## 五、数字可信度分级

写作时给每个数字心里打一个级别;级别越高越可作硬结论。

| 级别 | 来源 | 标注 |
|---|---|---|
| **A 原文确证** | 原始文档/数据直给 | 默认即 A,不额外标 |
| **B 图源待复核** | 只从图上读出,口径或单位需复核 | 「(取自图,待复核)」 |
| **C 推断** | 由前提推算 | 「(推断)」并写出推导 |
| **D 待确认** | 无来源,需 owner 落实 | 「(待确认)」或省略,**绝不当 A 用** |

数值、阈值、机制性因果论断都适用;拿不准不用「听起来对」的数字填空。同一指标跨多份产物出现时级别与数值一致。

## 六、读图三拍

每张数据图配一段读图,三拍走完,不许只放图不给话:

1. **数字**——这张图最关键的一个数或对比(具体值)。
2. **为什么**——机制或原因,落到原因而非复述。
3. **怎么用**——对决策或下一步的含义。

例(控池对比柱状图):「同一批共同出现的人里,A 源给出城市的占 66.6%,B 源只占 9.0%,差 7.4×。分母是两源都见过的同一批人,消除了池子规模差,差距只来自信号能力。所以这部分增量不是采样口径造成的,值得接进召回。」

强结论图可加右上角一句话 takeaway 角标。

## 七、交互图表补充

- 缺失、加载中、超时、空态各有明确显示,不以 0 或空白代替。
- 指标卡带方向(↑↓)与对比基准(相对什么)。
- 图例可切换系列时,默认状态即读者最该看的那组。
