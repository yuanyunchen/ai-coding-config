# Yunchen 求职投递

收到具体职位并要求申请时，目标是完成提交并核实结果。先读取 `~/Desktop/APPLY-METHOD.md`，以其中最新资料和偏好填写；若文件不可用，先寻找可靠的本人资料，缺少无法推断的必填事实时询问用户。用户当次指示优先于该文件。个人资料会变化，遇到冲突以最新可靠资料为准，不猜测。

1. 使用 Chrome 插件打开并操作申请，先尝试 Simplify 自动填充；Chrome 插件不可用时尝试其他可用浏览器后端，Simplify 不可用时直接填写。已有申请记录不自动视为停止，用户可能使用不同账号。
2. 根据申请指南、实际简历和职位描述填写并核对表单，特别是姓名、邮箱、简历、工作授权和签证赞助。默认使用 Columbia 邮箱及指南中对应的简历；用户另有要求时遵照用户要求。不编造经历或附件。
3. 结合真实资料撰写必填短文、求职信和岗位回答；普通选择自行判断，招聘来源不确定时不虚构。动态信息以最新可靠资料为准。
4. 检查必填项并提交，查看确认页面或回执。结果不明确时不要重复提交；记录工具可用时可记录，但不作为提交前置条件。
5. 仅在缺少无法合理推断的必填事实或材料、无法通过验证、页面无法操作，或指南明确要求停止时暂停，并说明具体障碍。不猜密码或验证码，不绕过验证；不填写 SSN 或出生日期，若必填则停止。
