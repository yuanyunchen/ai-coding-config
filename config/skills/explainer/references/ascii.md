# ASCII 等宽图

用于公式驱动的多阶段链路、逐步推导、同名变量在不同阶段取值不同的场景。高层全景用关系图,不用 ASCII。来源:用户的 ascii-strategy-diagram 规范,改为 HTML `<pre class="ascii">` 落地。

## 写法

| 写法 | 表示 |
|---|---|
| `[ name ] (单位) 中文` | 一个实体对象 |
| `│` / `▼` | 主干流向,`▼` 指向下一个实体 |
| `│` 旁一句话 | 这条边的过程或公式 |
| `★【名称 阶段】` | 由某个命名系统/服务负责的阶段 |
| `IF ( 条件 ) … ELSE ( … )` | 分支,各分支指向自己的 `[ 结果 ]` |
| 产出 `├──► [ 信号X ]`,消费 `◄── 注入 [ 信号X ]` | 跨阶段信号就近引用 |
| 整行 `=` 包裹 `【第N阶段:…】` | 切分大阶段 |
| 分子 / `─` / 分母 三行 | 纯文本分式 |

## 原则

- **流程完整**:从最原始输入画到最终输出或反哺,不断链、不跳步。
- **实体即对象,边即过程**:框里放「算出什么」,连线讲「怎么算」;公式只用普通字符。
- **同名不同值拆分身**:`pCTR_rank` 与 `pCTR_charge` 是两个实体。
- **单主干、就近引用**:一条主干自上而下;跨阶段信号在产出处分出、消费处引回,不拉贯穿全图的竖轨;分支只产出结果节点,随后回到主干列,不越缩越右。
- **无凭空变量**:每个输入画出提供者并标身份。

## 宽度

- 每行显示宽度 ≤ **90 列**(中文与全角标点计 2 列,ASCII 与框线字符计 1 列),超过时 `<pre>` 可横滑但读者要滚动,尽量避免。
- 长中文尾注另起一行,缩进对齐到被注释项下方;长说明在逗号处断行;分隔线按 90 列截。
- HTML 中 `<pre>` 内的 `<` `>` `&` 写成 `&lt;` `&gt;` `&amp;`。

宽度自检:

```python
import unicodedata, sys
w = lambda s: sum(2 if unicodedata.east_asian_width(c) in 'WF' else 1 for c in s)
lines = sys.stdin.read().split('\n')
over = [(i + 1, w(l)) for i, l in enumerate(lines) if w(l) > 90]
print('max', max(map(w, lines)), 'over', over)
```

`scripts/check.py` 会对页面里所有 `pre.ascii` 自动做这项检查(中、高档)。
