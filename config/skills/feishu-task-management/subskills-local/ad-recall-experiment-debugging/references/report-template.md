## 给 mentor 的重点版

```markdown
结论：问题最早出现在 [A → B]，不是 [已排除项]。

证据：
1. [上游] 已有 [非空/QPS]：[链接]
2. [断点] 出现 [错误码/零输出]，源码含义是 [语义]：[指标链接] [源码链接]
3. 同机房对照 [recall_type] 正常，AID/CID 为 [值]：[链接]

当前最可能原因：[Online 配置/映射/节点字段]。
下一步：[最小验证动作]；如果通过，再查 [下一层]。
```

## 证据质量检查

- 结论是否指出“最后正常”和“第一个异常”，而不是只列现象？
- 每个数字是否有时间窗、region、聚合方法和链接？
- 是否区分 Online、Latest、已发布、已创建、已实际生效？
- 是否说明指标缺少哪些 tags，避免过度归因？
- 错误量级是否足以解释主要故障？
- 是否把事实、推断和待验证假设分开？
