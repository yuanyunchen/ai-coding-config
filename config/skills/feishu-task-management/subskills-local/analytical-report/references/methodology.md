# 分析报告方法论 — 读图三拍 · 诚实口径 · 对抗审查 · 调色板 · 验证

来自 Search×Pixel City 信号分析的实战沉淀。SKILL.md 给骨架,这里给可照抄的细节。

---

## 一、读图三拍(每张图都要走完)

不许「只放图不给话」。每张图配一段读图,三拍递进:

1. **数字** — 这张图最关键的一个数 / 对比(具体值,不含糊)。
2. **为什么** — 落到机制/原因:为什么是这个数。
3. **怎么用** — 对决策/下一步的含义(actionable)。

**范例**(控池柱状图):
- 数字:「同一批共同出现的人里,search 给出城市的占 66.6%,pixel 只占 9.0% —— 7.4×。」
- 为什么:「分母是两源都见过的同一批人,消除了『search 池子更大』的规模差,差距纯来自信号能力。」
- 怎么用:「说明 city 增量不是采样口径制造的,值得把 search 的 city 信号接进召回。」

强结论图额外加**右上角 takeaway 角标**(一句话拎走)。core 版图少,但每张都要说透。

## 二、诚实口径检查表(逐条过,这是可信度命根)

报告评审最常翻车在「夸大 + 掩盖」。交付前自查:

- [ ] **采样标注**:每个采样估计在**首次出现处**带口径小标(如「1/10 取模采样 mod(user_id,10)=0」)+ 一句校验说明;只报比率/占比;绝对数标「≈ / 上界」。**措辞别把取模说成「哈希均匀」**。
- [ ] **诚实反例**:有反例就摆(例:「250 国里 27 国 pixel 反占优,巴西/墨西哥等成熟市场信号更厚」),不只挑顺的讲。
- [ ] **断线不插值(no-interpolation)**:趋势缺点就断 + 标 ✕,**绝不连线**假装连续。超时未取标「超时未取」,不补 0、不外推。
- [ ] **geoname id → name**:展示一律映射成可读名;映射缺失回退原值并注明(本项目 245/250 国映射上)。
- [ ] **推导值透明**:非直测的(如某窗超时改由别的口径推导)给出**算式 + 口径等价性**,放折叠区让同行复核;标明「推导」非「实测」。
- [ ] **近似函数**:`approx_count_distinct` 等标「误差 <2%,不改方向」。
- [ ] **样本量与外推边界**:小样本结论标「仅基于 N 样本,不外推」。
- [ ] **恒等式自洽**:跨指标的恒等式当场可验(如分解三桶之和 = 总数);报告里给出可验证算式。
- [ ] **不同量别混**:数值接近但定义不同的量分开讲(本项目「广度 uplift +23.6%」分母=pixel城数 vs 「独有城占比 23.4%」分母=并集,数值接近系巧合,明确区分)。

## 三、对抗审查 —— ≥4 agent 并行 + 修复闭环

质量主要靠这步兜底。build + Playwright 复验后,**派多个子智能体并行**各盯一面,汇总 blocker/major 后修复、重 build、重审,直到无主要问题。

**派单模板**(每个 agent 一份,自带完整上下文 —— 子智能体无记忆,见全局 AGENTS.md Harness 板块「subagent(派发)」):

> 你在审一份数据分析报告(自包含 HTML)。报告文件:`<core/index.html 与 full/index.html 绝对路径>`。
> 事实源:`<findings/STATE 绝对路径>`。你的审查角度 = **【X】**(只盯这一面,挑刺要狠)。
> 用 webapp-testing(Playwright)打开两份 HTML 截图核对。产出:BLOCKER / MAJOR / MINOR 三级清单,
> 每条给「位置 + 问题 + 建议改法」。不确定的也提(标低置信)。不要改文件,只报告。

**五个角度**(至少派 4 个):
- **内容**:结论是否被数据支撑;有无过度声明 / 漏掉的反例;口径定义是否正确(本项目抓到「控池其实是 co-presence」)。
- **视觉**:配色一致性、标签是否重叠、坐标轴、图例、留白、移动端。
- **结构**:章节顺序、TOC 锚点是否对、编号连续、core/full 分工是否合理。
- **口径**:对照上面诚实口径检查表逐项核(本项目抓到「取模≠哈希」误称、断线插值)。
- **质疑(red-team)**:假装怀疑论同行,找最容易被攻击的薄弱论点,逼报告自证。

**修复闭环**:blocker/major 修进**单一来源**(`_shared.css` / `_*_body.html` / `_drill.py`),`python3 build.py` 重出 + assert 通过 + Playwright 重验。本项目 v4 跑到 0 blocker 才交付。

## 四、调色板与设计基线

- **双信号双色**:`正/主 = teal #1f6f8b`(深 `#14525f`),`次/对照 = orange #c8742a`(深 `#9c540f`)。
- **墨/纸**:主文字深海军 `#16202e`,暖纸底 `#f7f5f0`,卡片 `#fffefb`。
- **字体**:serif 标题(Iowan/Palatino/Georgia/Songti)+ 系统 sans 正文 + mono 数字;**无网络字体**(自包含 + 可离线)。
- **状态色**:通过 `#3f7a52` / 强调金 `#b8862b` / 警示用 pixel 深橙。
- 换主题:改 `_shared.css` 的 `:root` 变量 + `_charts.js` 顶部 `C` 对象(两处同步)。
