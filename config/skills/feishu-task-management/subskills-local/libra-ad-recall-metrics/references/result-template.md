# 指标结果模板

## 简版

```text
实验：<名称>（flight <id>，<region>）
窗口：<start> 至 <last_complete_day>，<timezone>

结论：ADVV <diff>，p <value>，<置信/不置信>。目标支路<是否起量>，<效率判断>；价值变化主要来自<事件>。

主指标
- 决策 ADVV：<diff>
- P-Value：<value>
- 趋势：<收敛/波动/回流；没有看曲线则写未展开>

召回支路（queue_id=<id>）
- pass count：<value>
- 支路独占消耗：<value>
- 支路总消耗：<value>
- 对照：<主路与其他支路比较>

商品支路（dpa_direct_id=<id>）
- 广告消耗：<value>
- 计费比：<value，越低越高效>
- 对照：<主路与其他支路比较>

事件拆解
- <event A>：转化 <diff>，价值 <diff>，消耗 <diff>，计费比 <diff>
- <event B>：...
- 解释：<高/低价值事件 mix 或单次价值变化；注明推断>

链接：<详情>｜<主报告>｜<所用深度分析>
口径：<过滤条件；不同数据源截止日；截图或实时>
```

## 写作规则

- 先写判断，再写证据；不复述所有列。
- 正向但不置信时明确写“不置信”，不说“实验显著提升”。
- 计费比下降写“效率提高”，上升写“单位价值成本变高”。
- 对照为 0 时不引用无意义的相对差。
- “原因”只有证据闭环后使用；否则写“主要线索/可能来自”。
- 没有查看的页面不留空占位，直接删掉对应小节。

## 历史同信号汇总

多信号同时回顾时固定按“信号 → 实验类型 → region/实验”分组。每个实验的展示标签只保留能区分同组实验的关键词，允许集合为 `catalog`、`保量`、`拆quota`、`T only`；未命中的其他差异默认省略。flight ID、region、日期和状态放在独立字段中用于追溯，不塞进差异标签。

已结束实验的主指标窗口从实际实验开始时间起，覆盖实验真实产出日，并追加 7 个已确认产出的回流数据日。展示统一写 `<nd>d + 7d`：`nd` 和后续 7 天都按报告实际有完整数据的产出日计数，不按自然日跨度换算；尚未产满 7 个有效回流日时明确写“回流未满 7d”，不得提前标成 `+ 7d`。

被排除的小流量实验不进入主汇总，但要在核验记录中保留 flight ID、长期运行日期证据、从未 ramp 的页面证据、同信号同口径下消耗持续相对极小的比较证据和链接。没有固定阈值或双重页面证据时保留该实验，不用“看起来很小”代替判断。
