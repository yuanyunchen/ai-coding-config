# Libra 实验周会报告

复用上一周报告的结构、措辞和版式，只替换本周实际变化。现有文档是首要模板；不要重新设计报告，也不要顺手改实验配置。

## 必读与调用链

1. 先读飞书入口 skill 的 `memory.md`、`subskills-workspace/lark-doc-writer/SKILL.md`，再读本 skill。
2. 浏览器操作使用可用的 Chrome/Browser 后端；禁止用 computer-use 控制网页。
3. 飞书读写走官方 `lark-cli`；写前 dry-run，写后回读并检查渲染结果。
4. 执行前完整读取：
   - `references/report-workflow.md`：端到端顺序与写入边界。
   - `references/metric-duration-rules.md`：ADVV、p 值、日期、d 数口径。
   - `references/screenshot-spec.md`：截图区域、插图和缩进规范。

## 成功标准

- 指定周会文档保持与上一周模板完全相同的章节顺序、列表层级、图片宽度和语言风格。
- 每个实验只记录实验标签/链接、d 数、决策 ADVV 和 p 值；不增加泛化结论或解释性废话。
- ADVV 必须来自 `决策广告主价值Diff%`；p 值必须点击该单元格后读取，不能从其他指标列推断。
- 日期取最后一个不显示“数据产出中”的日期；第一天按 0.5d。
- 已关闭且存在关后数据时写成 `运行d + 回流d`，后半段只表示关后回流。
- 每个要求截图的实验都有一张正确裁切、无多余留白、与文本同级缩进的截图；row search 不得漏图。
- 不修改 Libra 实验，不改用户未指定的飞书文档或其他实验。

## 执行纪律

- 不逐个向用户确认；从现有周会、实验记录和页面自行消解信息。
- 不把页面“数据产出助手”误判成“数据产出中”。
- 不把 `广告主价值(opt)` 当成 ADVV。
- 不写“暂不形成正向结论”“后续持续观察”等模板化空话；优先复用 0721/上一周的短句。
- 页面或权限确实阻塞时，先尝试其他允许的浏览器后端和只读入口；全部失败后才报告阻塞。

## 收尾检查

按 `references/report-workflow.md` 的检查表逐项验收。若只创建/维护本 skill，不得触碰周会文档。
