# 指标、日期与 d 数口径

## ADVV 与 p 值

- `ADVV` 在本周会中固定指 **`决策广告主价值Diff%`**。
- 禁止读取 `广告主价值(opt)`、其他 ADVV 近似列或汇总卡片代替。
- p 值不在主表文本中猜测：点击 `决策广告主价值Diff%` 的具体单元格，在展开的详情中读取 **`P-Value`**。
- 报告只记录 diff 与 p 值，保留页面精度和正负号：`ADVV +3.372%，p 35.952%`。
- 不根据正负或 p 值补写结论；除非模板本身存在且用户要求保留，否则不写“显著”“不显著”“暂不形成正向结论”等判断。

## 最后完整数据日

1. 从预计的最新日期开始查看指标。
2. 只要该日期的目标指标区域显示 **“数据产出中”**，该日就不计入，向前回退一天。
3. 第一个不显示“数据产出中”且指标表已有完整数值的日期，就是报告结束日。
4. 页面里的 **“数据产出助手”** 是组件名，不代表数据仍在产出，不能据此回退日期。

## 时长公式

所有日期先按页面展示的日历日期计算，不用当前日期替代最后完整数据日。

- 总观测时长：`最后完整数据日 - 开始日 + 0.5d`。
- 未关闭，或关闭日在最后完整数据日之后：只显示总观测时长。
- 已关闭且关闭日不晚于最后完整数据日：
  - 运行段：`关闭日 - 开始日 + 0.5d`。
  - 关后回流段：`最后完整数据日 - 关闭日`。
  - 显示：`运行段d + 关后回流段d`。
- `+` 后面的数字只表示关后回流，不是总时长，也不是关闭当天重复计数。
- 整数显示为 `8d`，半天显示为 `8.5d`；不写无意义的 `.0`。

使用：

```bash
python3 scripts/calc_duration.py --start YYYY-MM-DD --last-data YYYY-MM-DD
python3 scripts/calc_duration.py --start YYYY-MM-DD --close YYYY-MM-DD --last-data YYYY-MM-DD
```

脚本输出 JSON，`label` 字段可直接用于周会文本。若开始/关闭时间跨时区，以 Libra 详情页显示的 UTC 日期为准，除非模板明确采用其他时区。
