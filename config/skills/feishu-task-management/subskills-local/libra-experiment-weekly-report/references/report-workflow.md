# 周会报告端到端流程

## 1. 锁定模板与范围

1. 打开用户指定的本周周会文档、上一周报告和实验记录文档。
2. 以上一周报告为唯一版式模板，记录：章节顺序、实验顺序、列表层级、图片位置、图片宽度、标点和句式。
3. 从实验记录提取实验名、CID/flight id、实验链接、开始时间及必要备注；实验集合未变时不得新增、删除或改实验。
4. 若用户点名 0721 版本，语言和截图均以 0721 为最高优先级样例。

## 2. 逐实验采集

对每个实验建立临时记录，仅保留：实验标签/链接、开始时间、关闭时间（若有）、最后完整数据日、决策 ADVV、p 值、截图。

1. 打开 Libra 实验报告页，定位 `T&E Catalog 实验指标`。
2. 日期先选本周预计截止日；若指标区域显示“数据产出中”，按日回退，直到找到最后一个完整数据日。
3. 在第一张完整指标表中找到 `决策广告主价值Diff%`，读取 diff。
4. 点击该 diff 单元格，打开详情浮层并读取 `P-Value`。
5. 按截图规范截取同一指标区域。
6. 打开 `/libra/flight/<id>/edit` 或等价详情页，读取实验状态和精确起止时间；只读，禁止修改。
7. 用 `scripts/calc_duration.py` 计算展示用 d 数，不心算。

可以先收齐所有数据再批量写文档，但每条数值必须能回溯到对应实验和页面。

## 3. 生成文案

完全沿用模板的实验顺序和行结构。每条只写模板要求的最少内容：

```text
实验标签（实验链接）｜Xd｜ADVV +x.xxx%，p xx.xxx%
```

已关闭且最后完整数据日晚于关闭日：

```text
实验标签（实验链接）｜Xd + Yd｜ADVV -x.xxx%，p xx.xxx%
```

其中 `Xd` 是运行段，`Yd` 是关后回流段。不要新增结论句、趋势判断、置信解释或行动建议。保留上一周已有的必要标题和分组名。

## 4. 原位更新飞书

1. 更新前回读目标文档的块树或 XML，锁定需替换的文本块和图片块；不要整篇重建。
2. 写入前使用 dry-run；按原块位置更新文本。
3. 图片放在对应实验文本之后、下一实验之前，并保持与模板一致的父块、列表层级和宽度。
4. 替换截图时先创建/上传并确认新图渲染正常，再移除旧图；不要留下重复图或空图片块。
5. 不改标题、章节顺序、无关段落、其他实验或文档权限。

## 5. 验收

- 文本：实验数和顺序与模板一致；每条只有 ADVV 与 p 值等规定字段；无“暂不形成正向结论”等空话。
- 指标：所有 ADVV 都来自决策列；所有 p 值都来自点击后的详情。
- 日期：所有结束日都是最后完整数据日；没有把“数据产出中”的日期计入。
- 时长：首日 0.5d；结束实验的 `+` 后数字仅为关后回流。
- 图片：每个模板要求的实验都有图，特别检查 row search；截图不含导航、大片留白或下一张表。
- 排版：图片与对应文本同级缩进，宽度和 0721/上一周一致。
- 边界：没有修改 Libra、未指定文档或其他实验。

写后回读文档内容，并在浏览器中做一次可视验收；二者都通过才算完成。
