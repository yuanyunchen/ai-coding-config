# 截图与插图规范

## 基准

截图样式以 0721/上一周报告为准。目标是一眼看清实验名、告警和第一张完整指标表，而不是保存整个网页。

## 正确区域

每张图从 `T&E Catalog 实验指标` 标题附近开始，到第一张完整指标表的底边结束：

- 必须包含标题和能识别实验/日期的必要上下文。
- 必须包含 `决策广告主价值Diff%` 所在表格的表头与完整数据行。
- 与指标解释相关且模板中保留的告警可以纳入。
- 排除顶部/侧边导航、浏览器栏、无关筛选区、大片空白和下一张指标表。
- p 值浮层用于读数；最终报告截图是否保留浮层，以 0721 模板为准。浮层遮住关键表格时必须关闭后再截。

优先调整页面缩放、滚动位置和视口后直接截取目标元素/区域；不要依赖事后随意裁剪导致文字被切断。截图前确认没有 loading、tooltip 遮挡或横向截断。

## row search

row search 与其他实验执行同一截图规则，不得因页面布局不同而省略。验收时单独检查一次：文本块后必须紧跟对应图片块。

## 飞书插图

- 图片必须位于对应实验文字之后、下一实验之前。
- 图片块与实验文字使用同一父容器/列表层级，不能额外缩进或悬在列表外。
- 宽度、对齐和上下间距复用 0721/上一周对应图片；不要凭感觉设新尺寸。
- 上传前本地查看 PNG，确认没有裁边、模糊、错误区域或多余留白。
- 写后在飞书渲染页检查，不以 block API 成功响应代替视觉验收。
