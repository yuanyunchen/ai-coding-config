## 范例一：广告 oCPM 竞价计费链路（GSP 倒挂截断）

范例要点：端到端链路；节点皆为带单位的 `[ 对象 ]`；边为过程/纯文本公式；GSP 倒挂截断用 `IF / ELSE` 分支表达；`pCTR_rank` 与 `pCTR_charge` 已拆分；跨阶段的 `rank_bid_A` 用就近引用回到第三阶段比对。

```text
========================================================================
【第一阶段：广告 A 内部计算与排序】
========================================================================

  广告主 A 在后台设定的目标转化出价
            │
            ▼
    [ cpa_bid_A ]  (单位: 元/转化)
            │
            │ 乘以 A 的精排预估转化率 pCVR_A (转化/点击)
            ▼
   [ 原始 eCPC 期望 ] = cpa_bid_A * pCVR_A  (单位: 元/点击)
            │
            │ 乘以 策略调控系数 coef_A (PID/强化学习流控、控成本系数)
            ▼
    [ rank_bid_A ] = cpa_bid_A * coef_A * pCVR_A  (单位: 元/点击)
            │
            ├──► [ rank_bid_A ]  【核心安全阀门】最终点击限价保护
            │         （锁定一阶段最高价值评估）
            │
            │ 乘以 A 的精排预估点击率 pCTR_rank_A * 1000
            ▼
    [ eCPM_A ] = pCTR_rank_A * rank_bid_A * 1000
               = cpa_bid_A * coef_A * pCVR_A * pCTR_rank_A * 1000

========================================================================
【第二阶段：大盘排序确定赢家】
========================================================================

    大盘根据当前排序分的绝对值决定胜负（统一在展示维度竞争）：
    第一名：广告 A (eCPM_A = 100元)  <-- 赢得本次曝光！
    第二名：广告 B (eCPM_B = 80元)   <-- 它的分数成为计费秤砣

========================================================================
【第三阶段：GSP 异步计费与阀门截断】
========================================================================

  大盘拿着固定下来的竞价秤砣 [ eCPM_B ] = 80元，去扒 A 的流量外壳：
  【核心特征】oCPM 按展示计费，理论上直接以大盘第二名 eCPM_B 为基准。
  但为防止特征变化带来非最优解，系统按点击维度做一次安全对齐：

  1. 结算流重新计算或刷新更实时的：[ pCTR_charge_A ]

  2. 依据 GSP 反推广告 A 的 [ 理论结算点击价 eCPC_B ]：
                        eCPM_B
            eCPC_B = ──────────────────────
                     pCTR_charge_A * 1000
            │
            ▼
  【执行核心安全比对截断】
  比较双方：[ eCPC_B ]  vs  [ rank_bid_A ]
                          ◄── 取 [ rank_bid_A ]（一阶段点击限价）

  解密最终扣费逻辑：

  IF ( eCPC_B <= rank_bid_A )
      [ Charge_eCPM_A ] = eCPM_B + 0.01元 = 80.01元
      (安全！成功享受 GSP 优惠，按 80.01元/千次展示 向广告主 A 扣费)

  ELSE ( eCPC_B > rank_bid_A )
      [ Charge_eCPM_A ] = rank_bid_A * pCTR_charge_A * 1000
      （倒挂！计费点击率暴跌或出价被改，触发限价保护，
       按 A 自身点击上限折算成 CPM 扣费）
```

## 范例二：推荐广告全链路（仲裁 → 召回 → 精排 → 竞价 → 实时反哺）

多阶段、多命名系统的全景图。重点看：每个阶段都用 `★【… 阶段】` 突出所属服务；第0阶段产出的 `[ 信号A ]`/`[ 信号B ]` 不走右侧竖轨，而在后续阶段被消费处就近 `◄── 注入` 回来；末尾的模型反哺用一句文字回指闭环，全图始终只有一条主干。

```text
========================================================================
【第0阶段：入口网关、流量仲裁与特征旁路准备】
========================================================================

  [ 原始请求输入 ] (用户ID、设备环境、广告位ID)
         │
         │
         ▼ ★【Arbiter 阶段】
           入口流量仲裁：执行高并发频控校验、疲劳度过滤
           与全局大盘流控评估
         │
         ├──► IF ( 触发疲劳度上限/极低质 )
         │         ──► [ 流量截断中断 ]（生命周期结束）
         │
         └──► ELSE ( 放行通过 )
                     │
                     ├──► [ 信号A：用户当前疲劳度特征 ]
                     └──► [ 信号B：全局大盘流控调节系数 ]

========================================================================
【第一阶段：定向圈定与受众初筛（百万级 → 万级）】
========================================================================

  [ 大盘全量原始广告库 ] (规模: 百万级)
         │
         │
         ▼ ★【Audience 阶段】
           受众高级定向：调用底层人群包服务
           (Custom/Lookalike Audience)，执行高维向量
           距离检索与相似度扩量
         │
         ▼ ★【Targeting 阶段】
           硬定向条件过滤：对地域、年龄、性别、机型、
           网络环境等强显式物理属性，做布隆过滤器比对
           与倒排索引求交集
         │
  [ 初始候选广告集 ] (规模: 万级广告 ID 集合)
         │

========================================================================
【第二阶段：多阶段算法模型预估（万级 → 百级精准打分）】
========================================================================

         │
         │
         ▼ ★【Cypher 粗排阶段】
           轻量级算力召回：运行双塔神经网络模型，分别
           提取用户/物品向量做秒级内积计算，淘汰 90%
           低潜力广告
         │
  [ Top-N 精选广告集 ] (规模: 百级高价值广告 ID 集合)
         │
         ├── (输入: 细粒度上下文交叉特征、长期兴趣、实时互动偏好)
         ├── (输入旁路控制信号) ◄── 注入 [ 信号A ]
         │
         ▼ ★【Predict 精排阶段】
           重工业深度预估：依托高级特征工程，基于 Marine
           神经网络做高维稀疏特征交叉，深度预估超高精度
           pCTR / pCVR
         │
  [ 算法预估概率对 ] (包含: 每个广告的 pCTR_rank 与 pCVR_rank 物理概率)
         │

========================================================================
【第三阶段：智能竞价拍卖与机制重排（决出展示赢家）】
========================================================================

         ├── (输入: 广告主商业参数 [ cap_bid ] 目标转化出价)
         │
         │
         ▼ ★【Bidding 智能出价阶段】
           博弈出价控制：依据 oCPM/oCPC 策略，将多目标
           转化出价统一平准到千次展示期望收入
           └─ 核心竞价公式:
              eCPM = pCTR_rank * pCVR_rank * cap_bid * 1000
         │
  [ 广告竞争力分列表 ] (数据形态: 带有 [ 原始 eCPM ] 的广告列表)
         │
         ├── (输入旁路调节系数) ◄── 注入 [ 信号B ]
         │
         │
         ▼ ★【Reranker & Prime 重排阶段】
           博弈流控重排：结合大盘流控信号 B 微调预算调控
           系数，执行 GSP（广义第二价格）竞价拍卖与机制去重
         │
  [ 拍卖胜出决策 ]
    （包含: [ 胜出广告 A ] + [ 计费秤砣 eCPM_B（第二名分数） ]）
         │

========================================================================
【第四阶段：后验校准、安全阀门控制与样本反哺闭环】
========================================================================

         │
         │
         ▼ ★【Calibration (+Lens) 后验阶段】
           后验纠偏与出价健康度调控
           ├─ 1. 调用结算流刷新特征，得到真实点击率
           │      后验校准值 [ pCTR_charge ]
           └─ 2. 避免计价超额，反推理论计费点击价:
                  eCPC_B = eCPM_B / (pCTR_charge * 1000)
         │
         ├──► IF ( eCPC_B <= 最高健康限价 )（满足 GSP 优惠机制）
         │       │
         │       ▼ 计费公式应用
         │     [ 最终展示扣费标准 (Charge eCPM) ]
         │       = eCPM_B + 0.01元
         │
         └──► ELSE ( 触发机制倒挂/特征异常 )
                 ▼
               [ 限价保护扣费标准 ]
                 （强行折算控制 cost_ratio 0.8~1.2）
         │
         │  （两分支的扣费标准都下发客户端曝光，再进入反哺）
         ▼ (下发客户端曝光，用户产生真实行为)
  [ 原始曝光与行为日志 ]（异步 Ad Log 与 Union Ad Log）
         │
         ├── (输入)
         ▼
  [ Joiner 2.0 / XDT 2.0 ]（流式样本拼接过程）
         │
         │ 在线流式实时拼接：利用 Flink 算子以 req_id+cid
         │ 为键，对实时 Label 与 Feature 做滑动窗口匹配
         ▼
  [ 标注训练样本流 ]
         （引入 Fast Emit 机制：正例滤波打散 /
          负例采样与概率时间打散纠偏）
         │
         ▼ Sailor/Sail 训练框架：执行秒级分布式增量参数
         │ 更新，动态刷新 Embedding 权重
  ( 实时反哺更新至第二阶段的精排模型 [ Predict ] )
```
