# 检索指南 · 定位某任务的飞书文档(可复用)

> **定位**:整理日报时,某个任务**没指定 context 文件、需要自己找**时走这条标准路径,把该任务依据的飞书学习/产出文档找全。这是本 skill 检索逻辑的**单一权威**——compile.md 只指针回这里,不重复正文。
>
> **核心路径**:先读 KB 索引找近期文档链接 → 用文档搜索交叉核对并补索引未收录的 → 逐篇读全文。**每步飞书调用都用 `--as user`**(用户身份),否则搜索不可用。执行走官方 `lark-cli`(见 `feishu-task-management` 入口 + `cli.md`)。

---

## 一、读 KB 索引「🤖 个人知识库索引(AI)」(第一入口)

- 用 `lark-cli docs +fetch --api-version v2 --doc Iw9jdKE3IoD2t1xMa9qucpz8s0c --as user` 读索引全文。
- 看**文末「新增项」段**:它列近期学习文档(标题 + token),是找当天/近期任务对应文档的第一入口。命中目标即拿到 token。
- 索引正文的主题分节(如「Signal / Pixel 信号体系」)也指向同主题文档,可顺带核对。

## 二、文档搜索交叉核对 + 补索引未收录的

- 用 `lark-cli drive +search --query "<中文关键词>" --as user`(文档搜索,取前若干条;可按文档类型过滤)。
- 用途有二:① 核对索引拿到的 token / 标题是否一致;② 补索引「新增项」**未收录**的文档(如更细的深档、原始溯源文档)。索引不全时靠这步补齐。
- 注意:搜索返回的实际标题可能比记忆里的多/少后缀(如多「· 学习文档」),以搜索结果为准。

## 三、逐篇读全文

- 对每个 token 用 `lark-cli docs +fetch --api-version v2 --doc <token> --as user` 读全文。
- 拿到全文后,日报里要引用的口径/数据逐条**核对自原文**,不凭印象。大文档按关键词/大纲定位需要的章节,不必整篇全读。

---

## 要点

- **索引「新增项」段 = 找近期学习文档的第一入口**;索引不全时用 `drive +search` 按中文关键词补。
- **每步飞书调用都用 `--as user`**(索引读取、搜索、读全文三处都要)。
- 按文件夹遍历通常**不必**——索引 + 搜索已足够定位。
