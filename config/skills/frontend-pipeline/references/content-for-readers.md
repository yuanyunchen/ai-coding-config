## 七、多页交付物(dashboard + 关系图 + 说明页 + README 一起交付时)

> 2026-11-04 沉淀(posthog-dashboard:三个页面与 README 之间数字、风格、语言各自漂移)。

- **一套 token**:所有页面共用同一组颜色、字体、卡片材质变量,从第一个页面就定下,不靠后期换肤统一。
- **数字只有一个来源**:页面上的数字从同一份数据文件生成;说明页、README、架构图里手写的数字,发布前逐个对回数据文件。实测:召回人数一处 82 一处 84、成本 $7.35 与 $7.76,同一次交付里三处不一致。
- **配套页入口放首屏顶部**:主页面顶部一行链到关系图、方法说明,不埋在页脚。
- **对外只保留一种语言**:读者用哪种语言就只发哪种,另一种语言的版本不并列上线。
- **本地双击和部署后都能打开**:数据用 `.js` 文件或内联,不依赖 `fetch` 本地 JSON(`file://` 下会被浏览器拦截,实测表现为「打不开」)。
